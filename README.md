
# Giftsbyfunmi

A responsive website for Giftsbyfunmi, a souvenir and customized gift business offering personalized gifts for weddings, birthdays, special occasions, and memorable celebrations.

## Live Website

[View Website](YOUR_LIVE_WEBSITE_URL)

## About The Project

Giftsbyfunmi is a business website designed to showcase customized gifts and souvenir products. It provides visitors with an easy way to explore available products, learn about the business, and make enquiries or place orders through WhatsApp.

The website focuses on a clean, user-friendly interface, responsive layouts, and a simple browsing experience across different screen sizes.

## Features

- Responsive design for desktop, tablet, and mobile devices.
- Clean and user-friendly interface.
- Product showcase section.
- Product cards with images and descriptions.
- WhatsApp integration for enquiries and orders.
- About section introducing the business.
- Social media links.
- Smooth navigation and scrolling.
- Responsive navigation menu.

## Products

Some of the products featured include:

- Customized mugs
- Tote bags
- Water bottles
- Jotters
- Food flasks
- Resin key holders
- Wedding souvenirs
- Birthday souvenirs
